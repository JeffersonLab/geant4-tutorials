# Instructions for mail merge from a spreadhsheet

## Naming check

Communicate to participants that if the name on the badge has wrong spelling
they should contact us to fix it.

## Create spreadsheet 

For example it can be a new Numbers document 
with data pasted rom the registration page

One option is to have first and last name in 
separate columns, and add a "Full Name" colum with:

```
=A2 & " " & B2
```

where A2 is the first name and B2 is the last name.


## Import Spreadsheet into Pages

In Pages, click the Document button (top-right) to open the 
right sidebar.

1. Choose Mail Merge in the sidebar.
2. Once you select the field name the Add Merge Field button will 
be clickable. 
3. We can add a new spredsheet, and select the desired
sheet in case there are more than one.

> [!NOTE]: this will import the spreadsheet into the Pages 
> document, any further changes to the spreadsheet will not be reflected
> in the Pages document. If you want to update the data, you will need to
> re-import the spreadsheet.


## Produce the certificates

Click Merge in the sidebar.
